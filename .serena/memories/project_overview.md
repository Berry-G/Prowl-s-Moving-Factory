## 확정 결정 (사용자가 직접 고름 — 뒤집지 말 것)

1. **마을 고용 + 행군** — 유닛이 실제로 걸어간다. 즉시 설치 아님 (ADR-0001)
2. **직교 격자** — Isometric Tilemap 쓰지 않음. 쿼터뷰는 표현 계층에서만 (ADR-0002)
3. **블로킹 없음** — 순수 사격형. 명일방주식 저지 메커니즘 없음 (ADR-0003)
4. **경로 그래프 + 통행 권한 플래그** — A*/NavMesh 금지. 지름길은 보호대상 전용, 적 통행 불가 (ADR-0004)
5. **물리 엔진 미사용** — Rigidbody2D/Collider2D/Physics2D 안 씀 (ADR-0005)
6. **런타임 UI는 uGUI** (ADR-0006)

### 지름길 기믹이 만든 필연적 부작용

지름길이 열리면 모체·적이 보호대상에 **도달 불가능**해져 얼어붙는다.
반드시 "도달 가능한 최근접 노드로 향한다" 폴백을 구현해야 한다. (TASKS P-11 / P-16)

## 기획자가 직접 만지는 영역 (대신 채우지 말 것)

- 스테이지 목록, 서사·대사, 언어 장벽 설계, 수집형 텍스트
- 밸런스 수치 (ScriptableObject `.asset`) — 그래서 매직 넘버 금지가 강제 규칙이다
- 스테이지 Tilemap 저작
