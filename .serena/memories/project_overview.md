## 문서가 어디에 있는가

`.docs/` 아래가 진실이다. 코딩 전에 반드시 읽는다.

> **🔴 정정 (2026-08-30 실측) — `.docs/` 와 `.serena/` 는 실제로는 git 이 추적한다.**
>
> `.gitignore` 13·14행에 `.docs/` `.serena/` 가 있는 건 맞다. **하지만 파일들이 이미 추적 중이라
> gitignore 가 적용되지 않는다** (gitignore 는 untracked 파일에만 작동한다).
> 확인: `git check-ignore -v .docs/GDD.md` → 무시 대상 아님 / `git ls-files .docs` → 전부 나옴.
>
> → **문서를 고치면 `git status` 에 뜨고, 커밋하면 리포에 올라간다.**
>   `.serena/memories/*.md` 도 마찬가지다. "안 올라가니까 괜찮다" 고 생각하지 마라.
> → 예전 메모에는 "커밋 대상이 아니라 git status 에 안 뜬다" 고 적혀 있었다. **틀린 정보였다.**
> → 사용자 의도(2026-08-27 "개인 작업용이라 안 올려")와 실제 동작이 어긋나 있다.
>   문서를 커밋에 포함할지 애매하면 **사용자에게 물어라.**
> → 그래도 큰 문서 개편 전에는 `.bak-<날짜>` 를 떠 두는 편이 안전하다 (커밋 전이면 되돌릴 수 없다).

## 확정 결정 (사용자가 직접 고름 — 뒤집지 말 것)

1. **마을 고용 + 행군** — 유닛이 실제로 걸어간다. 즉시 설치 아님 (ADR-0001)
2. **직교 격자** — Isometric Tilemap 쓰지 않음. 쿼터뷰는 표현 계층에서만 (ADR-0002)
3. **블로킹 없음** — 순수 사격형. 명일방주식 저지 메커니즘 없음 (ADR-0003)
4. **경로 그래프 + 통행 권한 플래그** — A*/NavMesh 금지. 지름길은 보호대상 전용, 적 통행 불가 (ADR-0004)
5. **물리 엔진 미사용** — Rigidbody2D/Collider2D/Physics2D 안 씀 (ADR-0005)
6. **런타임 UI는 uGUI** (ADR-0006)

### 지름길 기믹이 만든 필연적 부작용

지름길이 열리면 모체·적이 보호대상에 **도달 불가능**해져 얼어붙는다.
반드시 "도달 가능한 최근접 노드로 향한다" 폴백을 구현해야 한다. (TASKS P-11 / P-16)
