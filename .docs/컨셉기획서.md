# 1. 게임 개요

## 1.1 시놉시스

인류가 멸망한 먼 미래, 지구에는 여전히 생명체들이 살아간다. 이들은 끝없이 진화하며 인류의 발자취를 따라간다.

하지만 어느 날 냉동 동면된 한 소년이 깨어난다. 깨어난 소년은 무언가에 이끌린 듯 달린다. 소년의 생체 신호를 감지하고 가동하는 로봇들. 소년은 도망치고, 로봇들은 쫓는다.

이를 관찰하는 지구의 새 주인들은 숲을 부수며 시끄럽게 몰려드는 로봇들을 경계하고, 로봇들의 적으로 보이는 소년을 돕는다.

> **플레이어의 자리:** 플레이어는 소년이 아니다. 소년을 돕기로 한 **지구의 새 주인들** 쪽이다.
> 그래서 병력이 "설치되는 포탑"이 아니라 **"마을에서 나와 달려오는 이웃"** 인 것이 서사적으로 맞다.
> v2.0의 조작 변경은 이 관점과도 맞물린다.

## 1.2 장르 / 플랫폼 / 타겟

| | |
|---|---|
| **장르** | 타워 디펜스 (역방향 · 호위형) |
| **플랫폼** | PC (Steam) · Windows / Linux(Steam Deck 대응 검토) |
| **타겟** | 기존 타워 디펜스 특유의 지루한 반복 패턴에 회의감을 느끼는 **10~20대 미드코어** 유저<br>가볍게 게임을 즐기고 싶은 **30대 캐주얼** 유저 |

> ⚠️ **타겟과 조작 난이도의 긴장:** 행군 시스템은 즉시 설치보다 진입장벽이 높습니다.
> 캐주얼 타깃과 충돌할 수 있으므로, 프로토타입 플레이 테스트에서 **"행군 대기가 지루하다"** 는 반응이 지배적이면 하이브리드로 후퇴를 검토합니다 (`ADR-0001` 재검토 조건).

# 2. 핵심 컨셉

## 2.1 기존 타워 디펜스와의 차별점

기존 타워 디펜스는 출발지에서 생성된 몬스터가 목적지에 도착하면 라이프 포인트가 깎이고, 0이 되면 게임 오버, 웨이브를 모두 막으면 승리하는 형태다.

본 게임은 여기서 **방향을 뒤집는다.**

- 출발지에서 탈출 지점으로 향하는 **보호대상**이 생성된다
- 곧이어 **처치 불가능한 모체(母體) 몬스터**가 스폰된다
- 모체는 보호대상보다 **느리지만**, 보호대상을 향해 **지속적으로 이동**하면서 보호대상보다 **빠른 일반 몬스터를 계속 생성**한다
- 보호대상이 사망하면 게임 오버, 탈출 지점에 도착하면 클리어

**핵심은 여기다: 모체가 움직이므로 적의 생성 지점이 계속 바뀐다.** 지금 잘 막고 있는 방어선은 30초 뒤에 무의미해진다.

### v2.0에서 강화된 부분 — 재배치가 "돈"이 아니라 "시간"이다

기존 타워 디펜스에서 재배치는 자원 문제였다. 돈만 있으면 즉시 해결된다.

본 게임에서 병력은 **마을에서 고용되어 목적지까지 실제로 걸어간다.**

- 자원이 넉넉해도 **늦게 보내면 늦게 도착한다**
- 지금 위험한 곳으로 보내면, 도착했을 땐 이미 모체가 지나가 있다
- 따라서 플레이어는 **"지금 여기"가 아니라 "곧 저기"** 로 병력을 보내야 한다

→ 이것이 이 게임이 만들려는 감정이다: **예측하고, 미리 움직이고, 늦었을 때 아까워하는 것.**

### 두 번째 선택지 — 지름길

플레이어는 자원을 지불해 **보호대상만 지나갈 수 있는 지름길**을 열 수 있다. 적과 모체는 이 길로 따라오지 못한다.

- 열면 추격자와의 거리가 단숨에 벌어진다
- 하지만 그 자원은 병력에 쓸 수 있었던 자원이다

→ **"돈으로 시간을 산다."** 병력이냐 거리냐. 매 판 반복되는 선택이 하나 더 생긴다.

## 2.2 핵심 재미 포인트

기존 타워 디펜스는 한번 포탑을 설치하면 이후 개입할 여지가 적어, 사실상 **관전에 가까운** 플레이 경험을 제공한다.

본 게임은 모체의 이동에 따라 방어선을 지속적으로 재구성해야 하므로, 플레이어에게 **끊임없는 판단과 대응**을 요구한다.

세 가지 층위로 정리하면:

| 층위 | 플레이어가 하는 일 | 이걸 만드는 장치 |
|---|---|---|
| **읽기** | 모체가 어디로 갈지, 어느 마을이 그 방향을 커버하는지 판독 | 마을 배치 · 경로 구조 |
| **예측** | 도착 시간을 역산해 "지금" 고용 결정 | 행군 시간 |
| **저울질** | 병력에 쓸까, 지름길에 쓸까 | 단일 자원 · 지름길 비용 |

이를 통해 반복 플레이에서 오는 지루함을 방지하고, 매 판마다 다른 전개를 경험하게 한다.

# 3. 핵심 게임 루프

```
【시작】
  보호대상 생성 → 정해진 경로를 따라 자동 이동 시작
  일정 시간 후 모체 몬스터 생성 (보호대상 뒤쪽)

【반복】
  1. 모체가 보호대상을 향해 이동 (보호대상보다 느림)
  2. 모체가 일정 간격으로 일반 몬스터 생성 — 생성 위치는 모체의 현재 위치
  3. 일반 몬스터가 보호대상보다 빠르게 이동해 보호대상을 공격
  4. 플레이어가 마을에서 유닛을 고용
       → 유닛이 목표 지점까지 행군          ← ★ 여기서 시간이 흐른다
       → 도착 후 자리를 잡고 사격 시작
  5. 모체가 계속 이동 → 기존 배치의 커버 범위가 무의미해짐
  6. 플레이어가 새 위치로 다시 고용 (비용 = 자원 + 행군 시간)

【선택】
  자원을 지불해 지름길 개방
    → 보호대상이 경로를 바꿔 앞질러 감
    → 적과 모체는 따라오지 못함 → 추격 거리 벌어짐
    → 대신 병력에 쓸 자원이 줄어듦

【변수】
  보호대상이 특정 지점 도달 시 모체가 버스트 모드 진입
    → 이동을 멈추고 훨씬 빠른 속도로 몬스터 생산
    (2차 목표에서 구현)

【종료】
  보호대상이 탈출 지점 도달 → 승리
  보호대상이 도착 전에 사망 → 패배
```

# 5. 포지셔닝

타워 디펜스의 **낮은 진입장벽은 유지**하되, 방어선 재구성이라는 **지속적 개입 요소**를 통해 *쉽게 시작하지만 끝까지 손이 가는* 플레이를 지향한다.

타워 디펜스 장르를 선호하지만 배치 이후 개입 여지가 적어 아쉬움을 느끼는 유저들에게 새로운 경험을 제공한다.

### 한 줄 피치

> **"타워를 짓는 게임이 아니라, 이웃을 제때 불러오는 게임."**

### 30초 트레일러가 설명해야 할 것 (출시 준비 시 통과 조건)

1. 소년이 오른쪽으로 간다 (보호대상)
2. 뒤에서 공장이 따라오며 로봇을 뱉는다 (모체)
3. 마을에서 수인들이 달려 나온다 (행군)
4. 공장이 위치를 바꾸자 배치가 헛돌고, 플레이어가 다시 부른다 (핵심 루프)

**이 4컷으로 규칙이 설명되지 않으면 트레일러를 다시 만든다.**

### 쿼터뷰를 어떻게 만드는가 (v2.0에서 명확화)

명일방주의 화면은 **아이소메트릭 타일이 아니다.** 정사각 격자를 3D 카메라가 기울여 보는 것이다. 우리도 같은 방식을 쓴다.

- **논리는 정사각 격자** — 좌표 계산·사거리·클릭 판정이 전부 단순해진다
- **화면만 카메라를 기울여** 쿼터뷰로 보여준다
- 캐릭터는 **빌보드**(항상 카메라를 향해 서 있는 판)로 세운다

**➡️ 아트 발주 전에 카메라 기울임 각도를 먼저 확정해야 합니다.** 각도가 바뀌면 스프라이트를 전부 다시 그려야 합니다.

> 프로토타입 단계에서는 기울이지 않고 위에서 내려다보는 화면으로 봅니다. 재미 검증에 각도는 필요 없습니다.

### 톤 유지 규칙

- 로봇 격파 연출은 **폭발이 아니라 부품이 흩어지는** 표현
- 아군 유닛의 손실은 **사망이 아니라 후퇴/탈진**으로 연출
- 어두운 세계관은 **수집형 텍스트에만** 노출하고 본편 서사에는 넣지 않는다

### 세계관 — 2026-08-27 확정 (단계 7 G-00)

- 미래. **인류는 멸망했다.**
- 그 뒤를 잇는 **신인류 = 수인족**.
- 프로토타입에 등장하는 두 종족이 **첫 만남**이다: **고양이 수인, 쥐 수인.**
- **적 = 로봇.** 인류가 남긴 기계. 보호대상을 쫓는 것도, 모체가 뱉는 것도 전부 로봇.
- 로봇 격파 연출은 §12 의 규정("부품이 흩어지는")이 그대로 발효된다.

| | **고양이 수인** (`CatFolk`) | **쥐 수인** (`RatFolk`) |
|---|---|---|
| 컨셉 | 민첩하다 | 몸집이 작아 리치로는 승부가 안 된다 |
| 그래서 | **근접 공격** | **원거리 무기** |
| 사거리 / 공격속도 / 행군속도 | 짧다 / 빠르다 / 빠르다 | 길다 / 느리다 / 느리다 |
| 역할 | 경로 옆에 붙여 회전율로 녹인다 | 뒤에서 넓게 커버한다 |

- DPS 는 일부러 비슷하게 맞춘다. **선택의 축은 세기가 아니라 "커버 범위 vs 회전율"** 이다.
- 고양이가 행군이 빠르다 = **재배치에 유리**하다 (→ ADR-0008, ADR-0010).
- **"근접"은 블로킹이 아니다.** ADR-0003 은 유효 — 고양이 수인도 적의 이동을 막지 않고, 사거리가 짧을 뿐이다.
- 세계관 **설정과 병종 역할**까지가 개발 쪽 몫이다. 대사·스탠딩·수집형 텍스트는 기획자가 채운다.

### 종족(수인) 설정에 대한 전제

종족은 **기능적 차별화**(후각 정찰 / 활공 / 굴착 등 지형 제약)와 반드시 연결되어야 한다.
기믹으로 연결되지 않으면 수인 설정은 플레이어에게 **그냥 미술 취향으로 읽힌다.**

### ⛔ 재미 검증 게이트

프로토타입 완성 후 두 사람이 각자 5판 이상 플레이하고 아래를 판정한다.

1. 배치 타이밍을 놓쳤을 때 **"아깝다"** 는 감정이 발생하는가
2. 모체 이동으로 기존 배치가 무의미해지는 순간이 **명확히 체감되는가**
3. 보호대상이 3번째 마을에 닿기 **전에** 미리 고용하게 되는가
4. 지름길을 열지 말지 **실제로 고민**하게 되는가

> **2개 이상 실패하면 다음 단계로 가지 않는다.**
> 종족을 열 개 넣어도 재미없다. 컨셉으로 돌아가 핵심 루프를 다시 짠다.
> **여기서 몇 주 쓰는 것이 몇 달을 아낀다.**
