# ADR-0008. 재배치(선택·이동·회수)를 핵심 조작으로 승격한다

- 상태: 채택
- 날짜: 2026-08-27
- 뒤집는 결정: `GDD.md` §8 ("`Deployed` — 한 번 배치되면 스스로 움직이지 않는다") + §13 D-05 (기본값 "아니오")

## 결정

배치된 유닛을 **선택**하고, **새 슬롯으로 이동(재배치)** 시키고, **회수(환불)** 할 수 있게 한다.
D-05 는 "결정됨: 예" 로 닫는다.

## 맥락

- 원래 설계는 "배치 = 최종 결정"이었다 (GDD §8, §13 D-05 "아니오").
- 2026-08-27 사용자 판정: **"유닛을 배치하고 배치를 이동시킬 수 있는 게 핵심인 게임인데"**.
  모체가 계속 이동하는 이 게임에서 재배치는 부가 기능이 아니라 **핵심 동사**다.

## 부작용 — 이동은 공짜가 아니어야 한다 (여기가 핵심)

원래 재배치 비용 = *자원 + 행군 시간* 이었는데, 이동이 가능해지면 **자원 없이 행군 시간만** 내고 옮길 수 있다.
이러면 "재배치가 공짜"가 되어 GDD §4 의 긴장 구조(예측형 플레이, 잘못 보낸 병력의 대가)가 무너진다.

→ **비용 모델 확정 (B안):**
- 이동에도 **실제 행군 시간**이 든다 (즉시 텔레포트 없음 — 새 슬롯까지 걸어간다).
- 재배치 직후 **쿨다운 3.0초**. 쿨다운 중인 유닛은 다시 이동 명령을 받지 않는다.
- 종족 차등 **없음** — 고양이/쥐 모두 3.0초로 시작한다 (G-03 확정 목록).
- 행군이 빠른 고양이 수인이 재배치에 구조적으로 유리하다 — 이것이 종족 정체성과 맞물리는 지점이다 (→ ADR-0010).

## 대가

- `AllyUnit` 상태머신에 `Deployed → Marching` 재진입 경로가 생긴다 (GDD §8 갱신 완료).
- 기존 "배치 = 영구"를 전제로 쓰인 코드(배치 하이라이트, 슬롯 점유)가 재배치 경로를 함께 처리해야 한다.
- 회수/환불과 업그레이드(→ ADR-0009)가 이 조작 위에 얹히므로, G-02 ~ G-05 는 이 ADR 을 전제로 한다.
