# ADR-0012. 단계 7 — 합격선을 "시연 가능한가" 로 바꾼다

- 상태: 채택
- 날짜: 2026-08-27

## 맥락

P-20 까지 구현은 끝났는데, 사용자가 직접 굴려 본 판정:

> "프로토타입을 원한 건 맞지만, **지나치게 프로토타입스러워서 시연할 수 있는 퀄리티가 안 나온다.**
> 뭔가 완성되어서 게임의 형태를 갖추었다는 느낌부터가 안 든다."

## 결정

P-21 (재미 게이트) 앞에 **단계 7 — 시연 가능한 형태 만들기 (G-00 ~ G-21)** 를 넣는다.

| | P-21 게이트 (기존) | 단계 7 (신설) |
|---|---|---|
| 판정 대상 | 핵심 루프가 **재미있는가** | 게임이 **완성된 물건으로 보이는가** |
| 판정자 | 개발자 + 기획자 | **처음 보는 사람** |
| 합격선 | GDD §14 통과 조건 4개 | **5분간 시연할 수 있는가** |

- 그레이박스(도형·색만)는 유지한다. **아트 금지는 유효.** 그 안에서 완성도를 끝까지 올린다.
- 순서: `G-00 문서·ADR → G-01 병종 2종 → G-02 선택 → G-03 재배치` — **A 그룹(정체성·핵심 조작)을 건너뛰고 연출·UI 부터 하지 않는다.**
- 뒤집는 것: 재배치(→ ADR-0008), 업그레이드(→ ADR-0009), 수인족 세계관(→ ADR-0010), 사운드(→ ADR-0011).
- 뒤집지 **않는** 것: 적 처치 보상 금지(GDD §10), 블로킹 없음(ADR-0003), 물리 금지(ADR-0005),
  `ParticleSystem`/`Animator`/`Timeline` 금지, SO 밸런스, 새 씬 금지, 병종 3종째 금지.
- 사람이 확인해야 하는 항목(체크리스트 3~17번)은 G-21 에서 **한 번에 모아서** 확인한다.
