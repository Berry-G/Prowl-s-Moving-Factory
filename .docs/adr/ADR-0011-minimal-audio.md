# ADR-0011. 사운드 최소 세트 — 음원은 절차 생성, 외부 에셋 0개

- 상태: 채택
- 날짜: 2026-08-27
- 근거: 2026-08-27 사용자 판정 — "가벼운 사운드 정도는 넣어봄직하다" (단계 7 G-11)

## 결정

효과음 **최소 세트(7종 수준)** 만 넣는다: 사격 / 피격 / 로봇 격파 / 유닛 사망(후퇴) /
고용·배치 확인 / 지름길 개방 / 승패 판정.

- **음원 소스: 절차 생성** — 코드로 `AudioClip.Create` 로 만든다.
- **외부 에셋 0개.** 오디오 파일을 프로젝트에 넣지 않는다 (CLAUDE.md §4 의 외부 에셋 금지와 정합).
- 배경음악(BGM)은 이 단계 범위 밖이다.
- 볼륨·음소거 조절은 일시정지 메뉴(G-12)가 담당한다.

## 이유

- "싸우는 건지 맞는 건지 구분이 안 간다" 는 판정에서 소리가 가장 싸고 효과적인 보완 수단이다.
- 외부 에셋 도입은 별도 승인 대상이다. 절차 생성이면 승인 병목 없이 즉시 진행 가능하고, 완전히 되돌리기 쉽다.

## 대가

- 절차 생성 음원은 퀄리티 한계가 명확하다 (사인파/노이즈 조합 수준). "게임다운 느낌"의 최소선을 채우는 용도다.
- 진짜 음원은 게이트 통과 후 별도 결정(외부 에셋 도입 승인)으로 간다.
