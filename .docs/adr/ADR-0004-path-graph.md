# ADR-0004. 경로는 통행 권한을 가진 분기 그래프로 한다

- 상태: 채택
- 날짜: 2026-08-25

## 맥락

적의 이동 방식으로 세 가지가 후보였다: 보호대상 직접 추격(A* 그리드 패스파인딩), 고정 웨이포인트, 직선 이동.

사용자가 고정 경로를 택하면서 동시에 기획에 있는 기믹을 언급했다:
**"자원을 사용해서 보호대상을 지름길로 이동시키는, 적은 지름길 이용 불가"**

## 결정

경로를 **선형 웨이포인트가 아니라 방향 그래프**로 만든다. 각 엣지는 **누가 통행할 수 있는지**를 비트 플래그(`PathAgent`)로 갖는다.

- 지름길 엣지: `Allowed = Escortee`, `IsShortcut = true`, 초기 `IsOpen = false`
- 탐색은 다익스트라. `CanTraverse(agent)` 가 false 인 엣지는 그래프에 없는 것으로 취급
- 보호대상 / 적 / 아군 행군이 **같은 그래프를 다른 권한으로** 탐색한다

그리드 A* 와 NavMesh 는 쓰지 않는다.

## 이유

- 지름길 기믹은 "같은 맵인데 통행 가능한 사람이 다르다"를 요구한다. 선형 웨이포인트로는 표현이 불가능하고, 그리드 A* 로는 가능하지만 셀 단위 권한 관리가 훨씬 번거롭다.
- 노드가 수십 개 수준이므로 다익스트라의 비용이 무시할 만하다. A* 휴리스틱 버그 여지도 없다.
- 밸런스가 예측 가능하다. 적이 어디로 올지 확실하므로 배치 판단이 도박이 되지 않는다.
- 아군 행군에도 같은 그래프를 재사용할 수 있어 시스템이 하나로 끝난다.

## 대가

- 맵마다 노드를 손으로 저작해야 한다. (씬 저작 도구로 완화 — P-05)
- **모체/적이 지름길 때문에 보호대상에 도달 불가능해지는 상황이 필연적으로 발생한다.** 이때 얼어붙지 않도록 "도달 가능한 최근접 노드로 향한다"는 폴백을 반드시 구현해야 한다. (P-11 의 함정 항목)

## 재계산 정책

경로 재계산은 이벤트 기반으로만 한다. 매 프레임 금지.
트리거: ①스폰 시 ②보호대상이 노드 통과 시 ③자신이 노드 통과 시 ④지름길 개방 시(`OnGraphChanged`)
