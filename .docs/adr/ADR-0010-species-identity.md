# ADR-0010. 수인족 세계관과 병종 2종의 역할 분담

- 상태: 채택
- 날짜: 2026-08-27
- 근거: 2026-08-27 사용자 확정 (세계관 + 병종 정체성)

## 결정

**세계관:** 미래, 인류는 멸망했다. 그 뒤를 잇는 **신인류 = 수인족**. 프로토타입의 첫 만남은
**고양이 수인(`CatFolk`)** 과 **쥐 수인(`RatFolk`)**. **적 = 로봇(`Robot`)** — 인류가 남긴 기계.

**병종 2종:**

| | 고양이 수인 | 쥐 수인 |
|---|---|---|
| 공격 | **근접** | **원거리** |
| 사거리 / 공속 / 행군 | 짧다 / 빠르다 / 빠르다 | 길다 / 느리다 / 느리다 |
| 역할 | 경로 옆에 붙여 회전율로 녹인다 | 뒤에서 넓게 커버한다 |

- DPS 는 일부러 비슷하게 맞춘다. **선택의 축은 세기가 아니라 "커버 범위 vs 회전율"** 이다.
- 고양이의 빠른 행군 = **재배치에 유리** (→ ADR-0008 과 맞물린다).

## ⚠️ "근접"은 블로킹을 뜻하지 않는다

**ADR-0003(블로킹 없음)은 유효하다.** 고양이 수인이 근접이어도 적의 이동을 막지 않는다.
**사거리가 짧을 뿐**이고, 적은 그대로 통과하면서 맞는다.
블로킹을 넣으려면 ADR-0003 을 뒤집는 별도 ADR 이 먼저다. 임의로 넣지 마라.

## 범위

- 세계관 **설정과 병종 역할**까지가 개발 쪽 몫이다. 대사·스탠딩·수집형 텍스트·언어 장벽 설계는 기획자가 직접 채운다.
- 병종 3종째, 등급/승급은 이 단계에서 만들지 않는다.
