# ADR-0006. 런타임 UI 는 uGUI 를 쓴다

- 상태: 채택
- 날짜: 2026-08-25

## 결정

인게임 UI(고용 패널, 자원 표시, 결과 화면, 지름길 마커)는 **uGUI** 로 만든다. UI Toolkit 은 런타임에 쓰지 않는다.

에디터 확장(P-04 의 "타일맵에서 다시 읽기" 버튼 등)은 IMGUI 또는 UI Toolkit 어느 쪽이든 무방하다.

## 이유

- 이 게임의 UI 는 **월드 좌표에 붙는 요소**가 많다 (지름길 마커, 슬롯 하이라이트, 유닛 위 게이지). uGUI 의 World Space Canvas 가 이걸 그대로 해결한다. UI Toolkit 의 런타임 월드 공간 지원은 아직 이 용도에 편하지 않다.
- Input System 과의 연동(`InputSystemUIInputModule`)이 uGUI 쪽이 확실하다.
- 예제와 레퍼런스의 절대 다수가 uGUI 다. AI 보조 코딩에서 정확한 코드가 나올 확률이 높다.
- 프로토타입 UI 는 버튼 몇 개와 텍스트 몇 줄이다. UI Toolkit 의 이점(대규모 UI의 성능·구조)이 발휘될 규모가 아니다.

## 대가

- 나중에 옵션 메뉴 등 대형 UI 가 생기면 UI Toolkit 이 나은 선택일 수 있다. 그때는 **인게임은 uGUI, 메뉴는 UI Toolkit** 으로 혼용해도 무방하다 — 지금 통일할 필요가 없다.
