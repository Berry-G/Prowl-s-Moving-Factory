# ADR-0001. 배치 모델은 "마을 고용 + 행군"으로 한다

- 상태: 채택
- 날짜: 2026-08-25

## 맥락

컨셉 기획서(PDF)와 PMF-todo.md 가 서로 다른 조작 모델을 기술하고 있었다.

- PDF: 빈 슬롯을 클릭해 **즉시 타워 설치**, 재배치도 비용만 내면 즉시
- todo.md: **마을에서 유닛을 고용**하고, 유닛이 목적지까지 실제로 걸어가서 배치됨

두 모델은 상태머신·경로 시스템·UI가 전부 다르므로 코드를 쓰기 전에 하나로 정해야 했다.

## 결정

**마을 고용 + 행군 모델을 채택한다.**

유닛은 맵에 고정 배치된 마을에서 고용되고, 목표 배치 슬롯까지 경로 그래프를 따라 이동한 뒤 배치된다. 행군 중에는 공격하지 않는다.

## 이유

- 즉시 설치 모델은 "모체가 이동한다"는 차별점을 **비용 문제**로만 만든다. 자원만 충분하면 언제든 따라갈 수 있으므로 압박이 약하다.
- 행군 모델은 같은 차별점을 **시간 문제**로 만든다. 자원이 충분해도 늦으면 늦은 것이다.
- 이 게임의 목표 감정("배치 타이밍을 놓쳐서 아깝다")은 시간 압박에서만 나온다.
- 마을의 위치가 "이 방향은 몇 초 안에 커버 가능한가"라는 맵 판독 정보가 되어, 난이도 조절 레버가 하나 더 생긴다.

## 대가

- 구현량이 크게 늘어난다 (상태머신, 아군용 경로 추종, 슬롯 예약).
- 진입장벽이 올라간다. 캐주얼 타깃과 충돌할 수 있다.
- **행군 중 유닛 손실 여부(D-03)** 라는 미결정 사항이 따라온다. 이것이 프로토타입 1순위 관찰 항목이다.

## 재검토 조건

P-21 플레이 테스트에서 "행군 대기가 지루하다"는 반응이 지배적이면 하이브리드(짧은 쿨다운 + 즉시 배치)로 후퇴를 검토한다.
